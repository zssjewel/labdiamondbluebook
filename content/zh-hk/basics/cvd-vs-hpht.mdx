## 兩種種法一張表

| | HPHT 高溫高壓 | CVD 化學氣相沉積 |
|---|---|---|
| 點種 | 壓機模擬地底，碳溶喺熔咗嘅金屬入面，喺晶種上結晶 | 真空腔入面用微波將含碳氣體變成等離子，碳一層層沉積喺晶種上 |
| 溫度 | 約 1300–1600°C | 約 900–1200°C |
| 壓力 | 超過 87 萬 psi（極高） | 中低壓 |
| 時間 | 幾日至幾星期 | 幾星期 |
| 原石形狀 | 立方同八面體混合 | 扁平方塊 |
| 常見內含物 | 金屬熔劑（深色、反光） | 黑色石墨點 |
| 常見色調問題 | 偏藍（含硼）、偏灰 | 偏啡、偏灰、霧 |
| 生長後處理 | 有時需要 | 好常見，用高溫高壓去啡色 |
| 成品 | 真鑽石 | 真鑽石 |

兩種方法種出嚟嘅都係碳晶體，化學成分、硬度同天然鑽石一樣，係真鑽石，唔係仿鑽。

## HPHT：壓機入面種出嚟

HPHT 用大型壓機，喺極高溫度同壓力下，令碳溶入鐵、鎳、鈷等熔咗嘅金屬，再喺一粒細細嘅鑽石晶種上面慢慢結晶。因為係模擬地底環境，原理最接近天然鑽石。

- **好處**：一粒石一次過種完，顏色可以好白。
- **要留意**：熔劑可能留低金屬內含物，大粒嘅肉眼睇到係深色點；含微量硼會令石帶少少藍；有時會偏灰。

## CVD：一層層沉積出嚟

CVD 喺真空腔入面，用微波將甲烷同氫氣變成等離子，碳原子一層層落喺晶種上面，好似「印」一粒鑽石出嚟。可以中途停低睇進度，亦可以一次種好多粒。

- **好處**：冇金屬內含物，淨度可以好高；可以種大片晶體。
- **要留意**：種出嚟多數帶啡色，要再做生長後處理；停停種種會留低生長紋，嚴重嘅會令石睇落有少少霧；有時偏灰。

## 證書點寫

IGI 培育鑽石報告一般會寫：

- **生長方法**：CVD 或 HPHT。
- **生長後處理**：例如註明有冇經過處理改善顏色，冇處理嘅會寫「As Grown」。

GIA 新制評估同樣註明係培育鑽石，詳細可以睇[GIA 培育鑽石新制：Premium／Standard 點睇](/certificate/gia-premium-standard)。證書號碼要上化驗所網站核對。

## 揀石時要睇咩

1. **先睇 4C 同證書**：種法唔係最重要，同級數比較先。
2. **CVD 石**：叫商家俾相同片，睇有冇霧、啡、灰；問清楚有冇生長後處理。
3. **HPHT 石**：睇有冇深色金屬點、偏藍或者偏灰。
4. **大卡數**：一定要睇實物或者高清片，證書上嘅等級唔會寫晒透明度問題。
